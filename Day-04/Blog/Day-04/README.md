# 📅 Day 4 – SQL Fundamentals

## 🎯 Objective

Understand the basics of SQL and learn how to retrieve, filter, and organize data.

---

## 📚 Topics Covered

- SELECT
- WHERE
- DISTINCT
- ORDER BY
- LIMIT
- AND / OR / NOT

---

## 💡 What I Learned

SQL is one of the core skills required for Data Analytics.

Today I learned how to write simple SQL queries that retrieve only the required information from a database. Instead of manually searching through thousands of records, SQL makes data extraction quick and efficient.

Practicing these queries helped me understand how databases store and organize information.

---

## 🛠️ Skills Practiced

- Querying databases
- Filtering records
- Sorting data
- Removing duplicate values
- Applying logical conditions

---

## 🚀 Key Takeaways

- SELECT retrieves data.
- WHERE filters records.
- ORDER BY sorts results.
- DISTINCT removes duplicate values.
- SQL is the foundation of database analysis.
