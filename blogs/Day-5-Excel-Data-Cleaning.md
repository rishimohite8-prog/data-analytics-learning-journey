# Day 5 – Data Cleaning in Excel

## 📅 Date
05 August 2026

## 🎯 Objective
Today's goal was to understand how to clean raw datasets in Excel before performing any analysis. Since data collected from different sources often contains errors, duplicates, and inconsistencies, learning data cleaning techniques is an essential skill for every data analyst.

---

## 📚 Topics Covered

- Importance of Data Cleaning
- Removing Duplicate Records
- Handling Missing Values
- TRIM, CLEAN, and PROPER Functions
- Find & Replace
- Flash Fill
- Text to Columns
- Data Validation
- Sorting and Filtering
- Converting Data into Excel Tables

---

## 💻 Practical Work

Today I worked on cleaning a sample dataset by:

- Removing duplicate records
- Correcting inconsistent text formatting
- Eliminating unnecessary spaces using TRIM
- Splitting combined data with Text to Columns
- Applying Data Validation rules
- Using Conditional Formatting to identify errors
- Organizing data using Sort and Filter

---

## 🧠 Key Learnings

- Data cleaning is the most important step before analysis.
- Even small inconsistencies can lead to incorrect insights.
- Excel provides powerful built-in tools to prepare high-quality datasets.
- Well-structured data improves dashboard accuracy and reporting.
