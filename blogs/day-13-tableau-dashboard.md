# Day 13 — Building My First Dashboard with Tableau

Today I started working with another important Business Intelligence and Data Visualization tool — **Tableau**.

Rather than only exploring the interface, I focused on building a practical dashboard using sales data.

## What I Worked On

I used the Superstore dataset to explore sales performance and created an interactive dashboard.

My work included:

* Connecting Tableau to the dataset
* Exploring dimensions and measures
* Creating different types of visualizations
* Building KPI-style metrics
* Analyzing sales trends over time
* Comparing sales across categories
* Exploring regional performance
* Creating filters for interactive analysis
* Working with calculated fields and sorting
* Organizing the visualizations into a dashboard

## Dashboard Analysis

The dashboard helped me explore questions such as:

* How are sales changing over time?
* Which categories generate the most sales?
* Which regions perform better?
* Which segments contribute more to overall sales?
* Is there a relationship between sales and profit?

This made the learning experience more practical because I was not just creating charts — I was using them to investigate the data.

## What I Learned

Today I understood the importance of **Dimensions, Measures, Filters, Calculated Fields, and Dashboard Design** in Tableau.

I also realized that different visualizations answer different types of questions.

A line chart can help understand trends.

A bar chart can help compare categories.

A map can help analyze geographical performance.

A scatter plot can help explore relationships between metrics.

## My Biggest Takeaway

The most important lesson from today was:

> **Data visualization should make data easier to understand, not more complicated.**

A dashboard becomes valuable when someone can look at it and quickly understand what is happening in the business.
