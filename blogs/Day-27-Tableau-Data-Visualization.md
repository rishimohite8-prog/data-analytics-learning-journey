# Day 27 — Working with Data Visualization in Tableau

Today I worked with Tableau to understand how raw data can be converted into useful visual analysis.

I started by exploring the dataset and identifying the dimensions and measures that could be used for visualization.

I then created different visualizations to compare values across categories and identify patterns in the data.

The main focus was on understanding which visualization works better for different analytical questions instead of creating charts randomly.

### Work completed

* Connected a dataset to Tableau
* Explored dimensions and measures
* Created charts for comparison
* Worked with filters
* Compared categories
* Organized visualizations into a dashboard
* Used the dashboard to explore patterns in the data

One thing I found useful was seeing how the same dataset can communicate very different information depending on how the fields are selected and visualized.

The goal of visualization is not just to make data look better. It should make the information easier to understand and help answer a specific question.
