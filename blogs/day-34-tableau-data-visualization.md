# Day 34 — Tableau Data Visualization

## Work Done

Today I worked with a sales dataset in Tableau and focused on converting raw data into useful visual information.

The main work included:

* Connecting the sales dataset to Tableau.
* Preparing and exploring the available data.
* Creating visualizations for sales trends.
* Analyzing category-wise performance.
* Comparing sales across different regions.
* Identifying top-performing products.
* Building an interactive dashboard using charts, KPIs, and filters.
* Arranging the dashboard so that important information could be understood quickly.

## Analysis

The dashboard helped me look at the dataset from different perspectives instead of relying only on raw tables.

I focused on identifying patterns in sales, understanding which categories and regions performed better, and comparing product-level performance.

## What I Learned

This work gave me more practical experience in using Tableau for data exploration and visualization. The important part was not just creating charts, but selecting visualizations that actually helped explain what was happening in the dataset.

## Outcome

The final dashboard provided an interactive way to explore the sales data and identify important trends and performance differences.

**Focus:** Tableau → Visualization → Analysis → Insights
