# Day 23 — Building a GPay Transaction Dashboard in Power BI

Today I worked on a Power BI dashboard using GPay transaction data.

The workflow involved more than simply creating charts. I worked through the data preparation, modeling, calculations, and visualization stages.

I first worked on cleaning and preparing the dataset. After that, I worked with the data model and created DAX calculations for the metrics required in the dashboard.

The dashboard included KPI cards, charts, and filters to make the transaction data easier to analyze.

I used the dashboard to explore areas such as:

* Transaction trends
* Payment modes
* User activity
* Category-level spending
* Overall transaction performance

The main learning from this work was understanding the complete Power BI workflow:

`Data Cleaning → Data Modeling → DAX → Visualization → Dashboard Analysis`

Working through the complete process helped me understand how Power BI can be used not just for visualization, but as an end-to-end business intelligence tool.

**Day 23 completed — Power BI dashboard development and transaction analysis.**
