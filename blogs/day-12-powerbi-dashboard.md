# Day 12 — Building an Interactive Dashboard with Power BI

Today was a practical step in my Data Analytics learning journey.

Instead of only learning Power BI concepts, I worked on building a dashboard and understanding how raw data can be transformed into an interactive visual report.

## What I Worked On

* Imported and explored the dataset in Power BI
* Understood the structure and fields available in the data
* Created KPI cards to highlight important metrics
* Built charts for comparing categories and trends
* Added filters to make the dashboard interactive
* Worked on dashboard layout and visual organization
* Focused on making the report simple and easy to understand

## What I Learned

One of my biggest learnings today was that creating a dashboard is not simply about adding different charts.

A useful dashboard should answer questions such as:

* What is happening?
* Where is it happening?
* Which category is performing better?
* What trends can we identify?
* What information can help with decision-making?

## My Takeaway

Power BI helped me understand how data visualization connects technical analysis with business decision-making.

The goal is not to create a dashboard that looks impressive.

The goal is to create a dashboard that **communicates useful information clearly.**

This practical work also gave me more confidence in working with business intelligence tools.
