# Day 25 — Data Analysis with Python and Pandas

Today I worked with Python and Pandas to analyze a dataset programmatically.

I started by loading the dataset into a Pandas DataFrame and inspecting its structure.

The analysis included checking columns, data types, missing values, and basic statistics before moving into actual data exploration.

I practiced operations such as:

* Loading data with Pandas
* Inspecting DataFrames
* Checking missing values
* Filtering records
* Selecting specific columns
* Grouping data
* Calculating aggregated values
* Sorting analytical results

Using Pandas made it possible to perform repetitive data-processing tasks efficiently instead of manually working through individual records.

The workflow I practiced was:

`Load → Inspect → Clean → Filter → Group → Analyze`

This was another practical step toward building a consistent Python-based data analysis workflow.
