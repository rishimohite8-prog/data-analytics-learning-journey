# Day 35 — MySQL Data Analysis

## Work Done

Today I worked directly with datasets in MySQL and used SQL queries to perform data analysis.

The main work included:

* Retrieving required records using `SELECT`.
* Filtering data using `WHERE`.
* Sorting results using `ORDER BY`.
* Grouping records using `GROUP BY`.
* Using aggregate functions such as `SUM()`, `COUNT()`, `AVG()`, `MIN()`, and `MAX()`.
* Joining tables to combine related information.
* Comparing results across categories and other dataset dimensions.
* Writing queries to answer specific questions from the dataset.

## Query-Based Analysis

Instead of only practicing SQL syntax, I focused on using queries to extract useful information from the dataset.

The analysis involved breaking down larger datasets into smaller result sets, calculating metrics, and identifying patterns through query results.

## What I Learned

Working directly in MySQL Command Prompt helped me understand how SQL is used for practical data analysis.

I also got more comfortable with combining multiple SQL operations in a single query and thinking about the data problem first before writing the query.

## Outcome

The session improved my ability to work with structured datasets and use SQL queries to move from raw database records to meaningful analytical results.

**Focus:** MySQL → SQL Queries → Data Analysis → Results
