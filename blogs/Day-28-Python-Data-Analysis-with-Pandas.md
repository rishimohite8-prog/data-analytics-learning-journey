# Day 28 — Working with Pandas for Data Analysis

Today I worked with Python and Pandas to perform data analysis on a structured dataset.

I started by loading the dataset into a DataFrame and inspecting the available columns and records.

Before performing analysis, I checked the structure of the data and looked for missing values and inconsistent information.

I then worked with Pandas operations to filter, group, sort, and summarize the data.

### Operations practiced

* Reading data into Pandas
* Inspecting DataFrames
* Selecting columns
* Filtering records
* Handling missing values
* Grouping data
* Calculating aggregations
* Sorting results

For example, instead of manually calculating totals for different categories, Pandas allows the same operation to be performed programmatically across the complete dataset.

The workflow I followed was:

`Load → Inspect → Clean → Transform → Analyze`

This is becoming an important part of my data analytics workflow because Python can handle larger and more repetitive data-processing tasks efficiently.
