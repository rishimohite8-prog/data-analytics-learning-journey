# Day 22 — Building a Dashboard in Tableau

Today I worked with Tableau to turn a dataset into an interactive dashboard.

I started by connecting the dataset and examining the available fields. From there, I created visualizations to understand comparisons and trends within the data.

I worked with different views and then arranged them into a dashboard so that multiple parts of the analysis could be viewed together.

I also added filters so that the dashboard could be interacted with instead of remaining a static collection of charts.

### Work completed

* Connected the dataset to Tableau
* Identified relevant dimensions and measures
* Created visualizations
* Compared different categories and values
* Added filters
* Arranged multiple views into a dashboard
* Used the dashboard to explore trends in the dataset

The practical part of this exercise was understanding how individual visualizations can be combined into one analytical interface.

Rather than looking at individual numbers separately, the dashboard made it easier to explore relationships and patterns across the dataset.

**Day 22 completed — Tableau dashboard and interactive data analysis.**
