# Day 39 — Python: Analytical Dashboard

## Overview

Today I built a Python-based analytical dashboard using Pandas, NumPy, Matplotlib, and Plotly.

The goal was to create a reusable analytical workflow where data could be cleaned, transformed, analyzed, and visualized through code.

## Workflow

### 1. Data Loading

The business dataset was loaded into Python for further processing and analysis.

### 2. Data Cleaning

The dataset was examined and prepared for analysis by handling data quality issues and organizing the required fields.

### 3. Calculated Metrics

Additional metrics were created from the available data to support deeper analysis.

### 4. GroupBy Analysis

Pandas `groupby()` operations were used to compare categories and generate aggregated business metrics.

### 5. Category Comparison

Different categories were compared to identify performance differences and important variations.

### 6. Monthly Trend Analysis

Time-based analysis was performed to identify changes and trends across different periods.

### 7. Distribution and Correlation Analysis

The dataset was explored using distribution and correlation-based analysis to understand relationships between variables.

### 8. Ranking Visualizations

Ranking-based visualizations were created to highlight top and bottom-performing categories.

## Python Libraries Used

* **Pandas** — Data manipulation and analysis
* **NumPy** — Numerical operations
* **Matplotlib** — Data visualization
* **Plotly** — Interactive visualizations

## Key Learning

One of the biggest advantages of Python analytics is repeatability.

Instead of manually recreating a report whenever the data changes, the analytical process can be written as code and executed again on updated data.

## Analytical Process

The workflow followed a simple structure:

**Raw Data → Cleaning → Transformation → Metrics → Analysis → Visualization → Insights**

## Conclusion

This project improved my understanding of building analytical workflows in Python and demonstrated how programming can make business analysis more flexible, reproducible, and scalable.
