# Day 21 — Working with Pivot Tables in Excel

Today I worked with Excel Pivot Tables to summarize and analyze sales data.

Instead of manually calculating totals for every category or region, I used a Pivot Table to organize the dataset and quickly generate meaningful summaries.

I worked with fields such as region, product, and sales values to understand how the data was distributed.

The main operations I practiced included:

* Creating a Pivot Table from raw data
* Grouping sales by region
* Comparing products
* Calculating summarized sales values
* Applying filters
* Exploring the results through Pivot Table-based charts

The biggest advantage was being able to change the analysis without modifying the original dataset. By moving fields between rows, columns, filters, and values, I could look at the same data from different perspectives.

This was a practical exercise in turning a raw transactional dataset into a more useful analytical summary.

* Excel Pivot Tables

* Filtering
* Regional and product-level analysis
* Pivot-based visualization
