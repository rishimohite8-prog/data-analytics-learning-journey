# Day 24 — Data Cleaning in Excel

Today I worked on cleaning a raw dataset in Excel before using it for analysis.

The focus was on identifying common data-quality issues that can affect the accuracy of analysis.

I worked on:

* Removing duplicate records
* Handling blank cells
* Standardizing inconsistent values
* Cleaning unnecessary spaces
* Checking data types
* Formatting dates and numerical values
* Preparing the dataset for analysis

One important part of the process was checking the data before building any charts or calculations.

A dashboard can look correct visually while still producing incorrect results if the underlying dataset contains duplicates, inconsistent values, or incorrect data types.

This exercise reinforced the importance of treating data cleaning as an essential part of the analytics workflow.
