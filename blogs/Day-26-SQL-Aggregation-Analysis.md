# Day 26 — SQL Aggregation and Grouped Analysis

Today I worked on SQL aggregation queries to extract useful summaries from a dataset.

The focus was on using aggregate functions together with `GROUP BY` to move from individual records to meaningful analytical results.

I practiced functions such as:

* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`

I used these functions to calculate metrics across different groups in the dataset.

For example, instead of looking at every individual transaction, I could group the records by a particular category and calculate the total number of transactions or the total value for each group.

I also worked with sorting the aggregated results to make the output easier to analyze.

The workflow was:

`SELECT → GROUP BY → Aggregate Functions → ORDER BY`

This helped strengthen my understanding of how SQL can be used to convert raw transactional data into analytical summaries.
