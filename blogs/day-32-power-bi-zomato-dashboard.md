# Day 32 — Power BI Zomato Dashboard

## Overview

Today I worked on a **Power BI dashboard using a Zomato dataset**.

The objective was to take raw restaurant and order-related data and transform it into an interactive dashboard that could be used to analyze restaurant, cuisine, city and revenue patterns.

## Work Completed

### 1. Data Preparation

I started by preparing the dataset using **Power Query**.

The preparation included:

* Handling missing values
* Removing duplicates
* Checking column types
* Structuring the dataset for analysis

### 2. Data Modeling

I created relationships between the required tables to build a structured Power BI data model.

A proper model helped ensure that calculations and visualizations returned consistent results.

### 3. DAX Measures

I created measures for important KPIs and analysis.

The dashboard included metrics related to:

* Total Orders
* Total Revenue
* Average Order Value
* Restaurant Count

### 4. Dashboard Visualizations

I created multiple visuals to analyze the dataset, including:

* Order trends
* Orders by cuisine
* Orders by city
* Restaurant performance
* Revenue comparison
* Restaurant type analysis

### 5. Interactive Filters

I added interactive filters and slicers so that the dashboard could be explored from different perspectives.

Users can filter the analysis based on relevant dimensions such as city, cuisine and restaurant characteristics.

## Dashboard Workflow

The overall process was:

**Power Query → Data Model → DAX → Visualizations → Interactive Dashboard**

## What I Learned

The main learning from this project was understanding how different parts of Power BI work together.

Power Query handles the preparation, the data model organizes relationships, DAX handles calculations, and the visualization layer communicates the results.

## Tools Used

* Power BI
* Power Query
* DAX
* Data Modeling
* Interactive Visualizations
* Slicers

## Conclusion

Day 32 was a practical Power BI project where I worked through a complete analytics workflow using a Zomato dataset.

The focus was not only on creating visuals, but on understanding how **clean data, proper modeling and meaningful calculations contribute to a useful dashboard**.
