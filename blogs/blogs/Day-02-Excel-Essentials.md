# Day 2 – Excel Essentials for Data Analytics

Today, I focused on strengthening my Excel fundamentals, one of the most important tools in a data analyst's workflow. While Excel is often considered a basic spreadsheet application, it offers powerful features for organizing, analyzing, and visualizing data efficiently.

## What I Learned

### 1. Data Formatting

* Converted raw data into structured tables.
* Applied number, date, and text formatting.
* Used conditional formatting to highlight important values and trends.

### 2. Essential Excel Functions

Practiced commonly used functions including:

* `SUM()`
* `AVERAGE()`
* `COUNT()`
* `MAX()`
* `MIN()`
* `IF()`
* `COUNTIF()`
* `SUMIF()`

These functions help summarize data and automate repetitive calculations.

### 3. Data Cleaning

Learned techniques to prepare datasets for analysis:

* Removing duplicate records
* Handling blank cells
* Trimming unnecessary spaces
* Finding and replacing values
* Sorting and filtering data

Clean data is the foundation of accurate analysis.

### 4. Working with Tables

* Converted datasets into Excel Tables.
* Used structured references.
* Learned the benefits of automatic formatting, filtering, and dynamic ranges.

## Key Takeaways

* Clean and organized data makes analysis faster and more reliable.
* Excel functions reduce manual work and improve productivity.
* Tables simplify working with large datasets.
* Mastering Excel is an essential first step before moving to SQL, Power BI, and Python.

## Reflection

Today's learning reminded me that strong fundamentals create strong analysts. Every advanced dashboard or machine learning model starts with clean, well-structured data. Building these Excel skills will make future analytics tasks much easier and more efficient.

Looking forward to learning more and sharing my journey tomorrow.
