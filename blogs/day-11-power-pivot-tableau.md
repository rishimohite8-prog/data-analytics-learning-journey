# Day 11 — Power Pivot & Tableau

**Date:** August 9, 2026

Today I continued my Data Analytics Learning Journey by working with **Power Pivot and Tableau** and understanding how they fit into the overall data analytics workflow.

## What I Worked On

### 1. Power Pivot

I explored Power Pivot in Excel to understand how multiple related datasets can be handled through a data model.

Topics covered:

- Creating relationships between tables
- Building a data model
- Working with multiple tables
- Using PivotTables with Power Pivot
- Introduction to DAX
- Aggregating data through a data model

A basic Power Pivot workflow can be represented as:

**Multiple Tables → Relationships → Data Model → DAX/PivotTables → Analysis**

This helped me understand how relational data can be analyzed within Excel instead of keeping everything in one large table.

---

### 2. Tableau

I also started working with Tableau for interactive data visualization.

Topics explored:

- Connecting datasets
- Understanding dimensions and measures
- Creating charts
- Comparing categories
- Identifying trends and patterns
- Creating dashboards
- Presenting data through interactive visualizations

The main focus was understanding that visualization is not only about creating attractive charts. The visualization should help communicate an actual insight from the data.
